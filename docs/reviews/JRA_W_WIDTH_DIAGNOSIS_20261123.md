## わかったこと

1. **W は常に Static（ZAI_WIN）上位 N 頭と同じ集合**。10/11〜11/23 の結果確定 301R（新馬を除く）で例外なし。選定規則が Static 順位を並べ替えているのではなく、**何頭まで W に入れるか（幅）だけを決めている**。
2. Static 上位3以内の勝ち馬が W から外れた 5R（福島7・8・11R、東京1・11R）は、すべて BASE モードで差 0.35 を超えたことによる**幅の不足**。「能力順位で拾えていた馬を変換で外した」のではなく、「1頭軸にした」ことが原因。
3. BASE モード 158R：平均 W 1.04頭、W 捕捉 20.9%（Static 1位と同水準）。Static 上位2頭なら 39.9%、上位3頭なら 51.3%。
4. 正規化差の閾値を広げても、同じ頭数の Static 上位と同じか劣る（差 ≤1.25 で 36.7%／平均2.01頭 vs Static 上位2頭 39.9%）。差の値に順位以上の情報はない。
5. 残る 9R（Static 5位以下の勝ち馬）は幅ではなく基礎能力評価の問題。指数側の研究（20指数・挑戦者）で扱う。

## 研究候補（事前登録・記録のみ）

- `W_PLUS_STATIC2`（11/21 登録済み）：単頭 W に Static 2位を追加。点数は増える。
- `W_PLUS_STATIC2_SAME_BUDGET`（新規）：同上だが、組み直した券面を本番と同じ点数に切り詰める。**同じ点数で幅を広げて得か**を測る。

既知結果の再生（参考のみ、OOS ではない）：11/14〜11/23 の 102R で、本番 38.66%、W_PLUS_STATIC2 40.70%（投資+56,300円）、同点数版 37.10%。11/23 の 18R では本番 0円、W_PLUS_STATIC2 4,820円、同点数版 1,530円。

判定はオーナーのみ（11/30 中間、12/7、12/28）。前向き 100R 未満では昇格しない。
