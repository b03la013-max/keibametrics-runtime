1. KRS artifactディレクトリ作成より前の失敗で、Traceback保存先がなく二次的なUpload失敗となった。
2. StatusはIntentの存在からDISPATCHED_RUNNINGとし、Formalジョブの失敗を参照していなかった。
3. publish-onlyはStatusを再生成せず、既存ファイルをcommitするだけだった。
