# ケイバメトリクス地方版・血統BVI接続

地方版 Production numerical materializer に収集データの照合を接続する。
各馬の `bloodline_bvi_research` に父・母父の一致行、出典、研究用BVI、期間と欠測を返す。
レース全体の `bloodline_bvi_connection` にデータ識別子、ハッシュ、接続頭数を返す。
正式実行の `numerical_materialization_summary.json` にも接続監査と各馬の研究値・出典を残す。

## 収録範囲

- 2021〜2025年の地方全体・賞金上位50：父、父・2歳、母父、計750行。
- Odds Park Club の競馬場別補助表726掲載行：8競馬場、期間・条件は不統一。
- 賞金順と勝利数順の同じ血統、重複期間が含まれる。出走回数の合算に使用しない。
- 全15競馬場の同一5年・全出走母集団を収録したデータではない。

## BVI-L-R-v0.1（研究用・未較正）

AEI を「1なら中立52」に写像する独自の試験式：

`年別スコア = 52 + 48 × (AEI − 1) / (AEI + 1)`

各父・母父について、掲載されている年の年別スコアを出走頭数で加重平均する。
年ごとの出走頭数は重複馬を含むため、ここでは年の重みであり、5年のユニーク馬数ではない。
2歳父表は総合父表と重複するため算式から除く。未掲載年を0として補完しない。

`研究用BVI = (父スコア × 30 + 母父スコア × 20 + 52 × 50) / 100`

30・20は既存BVIg-Lの父・母父配点、残る距離・砂・競馬場・走法の合計50は中立。
父・母父未掲載も52とするが、`UNKNOWN` と観測配点0を明示する。
AEIは賞金効率であり、勝率・血統の因果効果・当該競馬場適性の推定ではない。
上位50の選択偏り、賞金クラス差、年齢差が残る。予測向上の検証は未実施。

## 正式BVIとの関係

正式BVIの同条件集計は、公式成績の最低30レース、1着5・2着3・3着2の点数、
父40・母父25・父父10・父系10・母父系10・父×母父5の情報を必要とする。
今回の集計に3着数、レース数、馬場・クラス・砂世代の母集団等がないため正式集計を作れない。
研究スコアは `canonical_components.BVIg-L` に代入しない。
既存の正式BVIg-Lは規程に従って52の `RULED-NEUTRAL` を維持する。
現行のTPI配点、静的予測、KRS、馬券、資金配分への昇格は行わない。

名古屋移転、大井の砂変更、盛岡の芝とダート、帯広のばんえいを混ぜた適性推定はしない。
競馬場補助行は参照表示専用。距離・砂適性スコアの計算には使用しない。

## 時点と完全性

manifest の `available_at` はこの接続データを固定した時刻。
Productionでは公式sourceの `source_freeze_at` と比較し、固定前・時刻欠落・時差なしの時刻は
`TEMPORAL_BLOCKED` とし研究スコアを返さない。壁時計による過去再計算の上書きを禁止する。
データのSHA-256不一致は計算を停止する。収録期間終了日も凍結日より前を必要とする。
このリリースは収集済み参考データの接続であり、新しい公式レースの取得や結果記録ではない。

検証：新規11件と既存24件、合計35件通過。歴史的12頭・348指標の再計算を維持。
現在時刻に変更した試験sourceによる接続テストは模擬実行であり、公式source receiptではない。
