## 発見した問題

1. 総合候補をW/P2/P3すべてへ広く流すと、Cartesian積の馬単・三連単が爆発する。MECのcoverage PASSは、与えられた構造を買い目へ運べたという検査で、予測・資金効率の合格ではない。
2. AKI合計→固定点数では列の失敗を扱えない。R50再計算では京都12Rの2/3着を落とし、旧的中を失った。軸の失敗リスクが高いとき、P3-AKI単独が低くても2/3着を保護する必要がある、という仮説を導いた。
3. 旧LOCAL AKI Paper7戦は2,651→92点にしたが、Frozen Recommendation PFSは56.10→14.89%。少点数化だけを成功判定にできない。
4. 同名のmapping_idでもProductionとSource-Derived Candidateは数値の意味・欠損補完が異なる。新候補を旧Candidate20戦へ転用すると的中10→1、9件の旧的中を失う。**転用は棄却**し、Shadow入口はProduction JRAのみ受け付ける。

## 新しい機構：軸リスクを列へ連動させる

R50のW-AKI・P2-AKI・P3-AKI・ASI・RSI mappingは既存正本を参照する。今回の新規部分は、列別の許容gapを連続的に変える下記の研究仮説。コードの比較テストで、9レースの各AKI・軸飛び・RSIをR50正式計算と一致確認。

指標ごとに競争力上位半分の標準偏差（下限1.0）で点差を割る。W基準はZAI_WIN最上位、P2基準はW基準馬を除いたZAI_PLACE最上位、P3基準はその2頭を除いたT3I最上位。優位な馬のgapは0。

| 列 | 指標 | 許容gap（各AKI・Risk・RSIは0〜100） |
|---|---|---|
| W | ZAI_WIN | 0.35 + 0.65×W-AKI/100 + 0.5×軸飛びRisk/100 |
| P2 | ZAI_PLACE | 0.8 + 1.2×P2-AKI/100 + 軸飛びRisk/100 |
| P3 | T3I | 1.2 + 0.8×P3-AKI/100 + 0.5×RSI/100 + 2×軸飛びRisk/100 |

全列は指標60以上、対応する裏付け指数3個のうち2個以上65を要件とする。WはRFI/CFI/PRI、P2はRFI/CFI/TPI、P3はRFI/CFI/F3S。新候補におけるCOREはgap0.35/0.8/1.2の範囲。COREの順序を馬単・三連単へ、拡張分を三連複へ集約し同一集合を重複購入しない。軸不安があるのにWが2頭成立しない場合、馬を無理に足さずPAPERへ。

この係数は結果確認後に作った仮説。京都12Rの欠落を観察したうえでP3の軸リスク係数を拡張したため、以下の成績は**探索内成績**であり検証済みの最適値ではない。外部変動は二時点の正式観測が無ければUNOBSERVABLE。観測不能を実際の荒れに読み替えない。堅決着補正は既存の正式条件が確認できるときだけ認め、このコホートでは未確認。資金超過でも候補馬・構造を削らずPAPERへ。新候補は外部観測の有無にかかわらず将来検証完了まで全件PAPER。
